# Bundled typefaces

All three families are licensed under the SIL Open Font License 1.1. The complete
license files are included beside the fonts; redistribution and embedding are
permitted under those terms.

- `NotoSans-Regular.ttf`: readable Latin UI; upstream [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf).
- `NotoSansThai-Regular.ttf`: Thai fallback and Thai UI; upstream [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansThai/NotoSansThai-Regular.ttf).
- `NotoSerif-Regular.ttf`: serif Latin titles; upstream [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSerif/NotoSerif-Regular.ttf).

Retrieved 2026-10-11. Use the Thai font as a fallback to preserve combining marks
and shaping for Thai localization; translation completeness is tracked separately.
